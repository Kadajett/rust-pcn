Cumulative corpus registry

Training data

Accepted datasets accumulate. A later stage is the union of earlier active data plus newly accepted sources, with early examples and control anchors replayed to resist forgetting.

Policy. Accepted datasets are not removed from future rehearsal. Licensing, attribution, leakage, and format checks gate a queued source before it becomes active.

Automatic cumulative admission

Active addition. Open-Jev release v2 is normalized on the fast-storage dataset volume: 79,116 training records and 1,327,173 byte-training windows. Calibration, validation, test, OOD labels, and privileged metadata remain outside weight training.
Train a bounded slice from every active retained corpus.
Checkpoint the exact post-final-batch PCN and SEAL state.
Continue each dataset forward until its last example, then traverse the same examples in reverse order without reversing prompts, answers, bytes, or label semantics.
After the newest real dataset completes both traversals, acquire and attribute the next approved Hugging Face source.
Only after every accessible real source is exhausted may the scheduler admit a bounded Jev-generated typed-supervision wave.

How data becomes training rows

Text and code

Files are split into fixed 64-byte windows. The next byte is the supervised target. Sensitive-looking filenames and excluded build/vendor directories are skipped.

Images

CIFAR-style records provide a label plus planar RGB pixels. A deterministic patch is selected and masked before training.

Typed decisions

Planned: state and question instructions are encoded separately, options are scored as variable candidates, and soft target distributions remain distributions rather than being collapsed to argmax.

Image-to-text

Planned: the image latent remains present throughout teacher-forced description tokens and generation.

Forward-only lineage

Freeze the newest finite checkpoint as the immutable parent.
Build the next stage from that parent, copying compatible weight blocks exactly.
Load every active prior dataset plus the new accepted source.
Replay early corpus examples and Pinball anchors during the same stage.
Measure new capability and retention without using poor quality as permission to jump backward.
Append every stage and corrective child to lineage without rewriting history.

Data still required

  • Instruction/response pairs for useful answers rather than continuation alone.
  • Image-caption and visual-question-answer pairs beyond Pokémon descriptions.
  • Long-context examples with explicit retrieval dependencies across distant positions.
  • Schema-conditioned structured-output examples covering nested and bounded values.
  • Calibration sets for Noul, Choice, and Score primitives.
