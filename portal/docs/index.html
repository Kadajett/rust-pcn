River Song

The model that exists today, the evidence shown on the training dashboard, the cumulative data entering it, and the forward-only path toward multimodal Noul, structured, and text output.

Forward-only invariant. Every finite checkpoint remains an immutable ancestor. New dimensions and capabilities are added by migrating the newest weights, initializing only new capacity, and replaying old datasets. Poor output triggers corrective child training—not a jump back to an earlier model.
Release naming. Internal model and checkpoint lineages v1 through v10 all belong to the public River Song v0.1 release. A lineage number describes architecture and migration state, not a public version.
