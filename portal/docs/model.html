Song

River is the predictive-coding base and lineage; Song is the model built on it with the project’s custom SEAL methods. Internal v1 through v10 labels identify forward-only architecture and checkpoint generations, not public releases: all remain River Song v0.1.

Input adapters

Text and code

Inherited training predicts the byte after a 64-byte bitplane window. The v5 task adapter also trains only response bytes from instruction, conversation, reasoning, code-instruction, and function-calling records while preserving a rolling prefix sketch.

Images

A deterministic 12 × 12 RGB patch occupies the sensory coordinates. V5 pairs held-in patches with textual class labels on the persistent token path; this is label grounding, not caption-level scene understanding.

Typed decisions

Typed Open-Jev records preserve their soft Noul, Choice, and Score target distributions. State, question, criteria, options, and rubric condition one shared typed coordinate.

Structured Pinball state

The original 512 normalized features remain compatible. The first three output coordinates map back to independent values in [0,1].

Weight preservation

The v3-to-v4 migration copied compatible first-layer rows, the middle matrix, the original three final-layer columns, and their biases exactly.
New sideband rows and new output columns were initialized without replacing the inherited values.
Non-Pinball batches freeze the original three output columns. Pinball rehearsal freezes the new output columns while exercising the shared trunk.
Every future widening starts from the newest finite checkpoint and copies every shape-compatible block. New capacity is added around it, never substituted for it.

Post-v5 text memory

Zero-gated causal attention decoder

Latent recurrence is enough to prove River can emit useful token sequences, but compressing an entire answer into 1,024 latent values will eventually lose exact names, references, syntax, and relationships. The forward successor therefore adds a small causal Transformer decoder without replacing the predictive-coding core or its token head.

Initial scale

Four decoder blocks, width 512, eight attention heads, 1,536-wide feed-forward paths, rotary positions, and tied 4,096-token embeddings. Approximately 15–20 million appended parameters.

Exact migration

All v5 tensors remain unchanged. With the new residual gate at zero, the child produces the same token logits as its parent before attention training.

Two memories

The PCN latent remembers what River was asked and what multimodal evidence it saw. The causal KV cache remembers exactly what the decoder has already said.

Honest model class

This descendant is a hybrid PCN–Transformer. Its text decoder uses causal attention and next-token cross-entropy; the shared multimodal core remains predictive coding. Documentation and model metadata must say so explicitly.

Forward-only. The attention path is appended to the newest finite descendant, starts behaviorally disabled, and is enabled through a growing residual gate. Failure produces another corrective child; it never removes the attention tensors or reloads an ancestor.

Active training focus

  • Improve fixed held-out typed calibration and candidate ranking without changing inherited outputs.
  • Train persistent response-token supervision across instruction, conversation, reasoning, and code datasets.
  • Improve paired image-to-label grounding before expanding to caption-level supervision.
  • Promote each new path only after its deterministic gate passes.
  • Use every accepted dataset cumulatively so no single evaluation family becomes Song’s identity.
